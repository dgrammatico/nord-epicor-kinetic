# Checkbox

A labelled check box for options in forms and dialogs.

**Consumer provides:** label, checked state.

- 18px box, 1.8px `icon` border, `radius-sm`; checked fills `icon` with an `on-accent` check. Label `text-body`, 10px from the box.
- Runs of checkboxes sit 6px apart; the box aligns with the left edge of the fields above; the last one sits `space-3` above the next field.
- The box and label share a vertical centre.
