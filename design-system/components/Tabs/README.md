# Tabs

The page-level tab row: rounded chips above a full-width divider.

**Consumer provides:** the tab labels and which is active.

- Each tab: `surface-raised` chip, `radius-md` on all corners, 10px × 18px padding, 6px apart, `text-body` label. Hover: `surface-hover`.
- Active: `surface-hover` chip, `accent` 600 label, 2px `accent` inset underline.
- The row sits 7px above a 1px `divider` that runs the full width; tabs never sit on the line or get clipped by it. Content starts 8–12px below the divider.
- An "add tab" (+) chip uses the same height and padding as the text tabs.
