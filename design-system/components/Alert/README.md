# Alert

Inline tinted message bars under the control they describe.

**Consumer provides:** the message and its kind (info, warning, error).

- `radius-md`, 6px × 10px padding, 13px text vertically centred, full width of the field above it, 8px below that field and 12px above the next.
- Info `info-tint` + `accent`; warning `warning-tint` + `warning`; error `danger-tint` + `danger-text`.
- No borders, no left-edge stripe, no decorative icons unless the platform supplies a real one (then centre it on the first line).
